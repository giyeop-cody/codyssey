## 🚀 클론 및 사용 방법

```bash
# 서브모듈 포함 전체 클론 (모든 과제 코드 포함)
git clone --recursive https://github.com/giyeop-cody/codyssey.git

# 이미 클론한 경우
git submodule update --init --recursive

# 최신 상태로 업데이트
git submodule update --remote --recursive
```
